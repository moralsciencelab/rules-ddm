## Format notes

- Manuscript figures: PDF or EPS preferred for submission; PNG at 300 dpi minimum
- Supplementary figures: PNG at 300 dpi
- Maximum width: 89 mm (single column) or 183 mm (full width) per NHB guidelines
- Font: match manuscript body font, minimum 6pt in final printed size
